# One look, step 2: pictures of the shared header and stylesheet

48 pictures from `docs/one-look/tools/shoot-site.mjs` (the built site served as the published site is laid out; 1440 x 1000 and
360 x 800; deviceScaleFactor 1): `<page>-<1440|360>-<theme>-<mode>.png` in Crystarium Dawnglass light and dark, Azure Dragoon dark and
Ul'dah Sultanate Gilt light. `measures.json` holds the computed `--paper`, `--seal` and header height of every picture: in each theme and
mode the Atelier's `--paper` and `--seal` equal Home's (Azure Dragoon dark: `#0e2257` and `#6ea2ff` on all six pages). All 24 desktop
pictures were looked at; the phone pictures were sampled (the Tracker's header fits 360 px in two rows, its search field is narrow).

- **Home:** the shared header: Main menu button, the "Command Center" wordmark, the app's pages with Home underlined; the status line has no row of its own.
- **Settings:** the same header on the same page, Settings underlined; the body is still the old Settings (moves later).
- **Submersibles:** the same header and nav with Submersibles underlined; the tab rail below is the page's own.
- **Lists:** the same header with Lists underlined; the Lists body is untouched.
- **Tracker:** the same header; the tool slot holds search, the Eorzea clock and Settings (the Index button shows only on narrow screens), the app's pages sit at the right; the tag line is gone.
- **Atelier:** the same header with the language menu and Settings in the tool slot; the Atelier now paints Azure Dragoon dark in Azure colours (`#0e2257`), like the other pages; the Command Center link is now the Main menu.
